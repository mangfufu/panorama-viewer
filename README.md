# 全景查看器

360° 全景图片在线查看工具，支持上传、拖拽浏览、截图导出。

## 功能

- 上传全景图片（支持拖拽和点击）
- 360° 全方位拖拽查看
- 鼠标滚轮缩放
- 截图导出当前画面
- 全屏模式
- 自动旋转（播放/暂停切换）
- 重置视角
- 多图管理
- 局域网访问

## 技术栈

- React 18 + TypeScript
- Vite
- Pannellum（WebGL 全景引擎）
- Zustand（状态管理）

## 开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

## 使用

1. 打开页面后，拖拽或点击上传区域选择全景图片
2. 鼠标拖拽画面旋转视角，滚轮缩放
3. 底部工具栏可截图、全屏、自动旋转、重置视角
4. 左侧列表可切换已上传的全景图
